# Coletor local temporário

A coleta passa para o PC do proprietário. A agenda de coleta nos servidores GitHub foi removida porque as três plataformas não conseguiram conectar à Câmara. O GitHub publica somente commits aprovados enviados à branch site-publicado.

O instalador preparado está na pasta outputs/coletor-pc do computador e foi entregue no chat. Abra INSTALAR.cmd pela conta normal do Windows: ele autentica via GitHub CLI oficial, configura Pages, cria a tarefa diária às 03h37 no fuso do Windows e roda o primeiro teste. O assistente não pôde registrar a tarefa da conta real a partir de sua conta isolada.

A tarefa só deve ser considerada instalada após esse passo; a publicação só é confirmada por estado.json com publicado:true e pela execução GitHub bem-sucedida. Os arquivos em pc/ documentam o instalador do pacote local; não são uma instalação independente sem os coletores, base inicial e GitHub CLI incluídos no pacote entregue.

O PC precisa estar ligado, conectado à internet e com a sessão Windows conectada. Falhas preservam a versão anterior. O coletor não depende de o chat ficar aberto. Não enviar credenciais pelo chat.
